# Community and help

Grafida is Free and Open Source Software (FOSS). It exists for and thanks to a community of passionate people. Code, help, and support are a community affair. Our community is hosted on GitHub for practical purposes.

If you have found a bug, please report it in the [issue tracker](https://github.com/grafida/grafida/issues). Please make sure it's reproducible, and you have included reproduction instructions which do not devolve into “it doesn't work with my site / my device”.

If you have an improvement to share, you can submit a [Pull Request](https://github.com/grafida/grafida/pulls). Kindly note that the maintainers have the final say on what goes into and out of the software.

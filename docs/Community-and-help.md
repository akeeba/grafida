# Community and help

Grafida is Free and Open Source Software (FOSS). It exists for and thanks to a community of passionate people. Code, help, and support are a community affair. Our community is hosted on GitHub for practical purposes.

If you need help, have a question, want to thank the developers, or just showcase how you're using this software, please use the [Discussions page](https://github.com/akeeba/grafida/discussions).

If you have found a bug, please report it in the [issue tracker](https://github.com/akeeba/grafida/issues).

If you have an improvement to share, you can submit a [Pull Request](https://github.com/akeeba/grafida/pulls).
